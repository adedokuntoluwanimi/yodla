## Design Context

### Users
Modern legal-drinking-age Nigerian hosts choosing drinks for dinners, gifts, weekends, and celebrations. The main job is to reach a confident, occasion-appropriate choice without working through an overwhelming catalogue.

### Brand Personality
Warm, bold, and editorial. The voice is concise, conversational, hospitable, and confident without feeling exclusive or pushy.

### Aesthetic Direction
Preserve Yodla's rich burgundy, ember-orange, cream, and near-black palette; oversized editorial display type; restrained mono labels; product-led photography; and mostly square controls. Drinks.ng is interaction inspiration for visible product browsing, not a layout or brand template. Avoid generic ecommerce chrome, fake urgency, noisy gradients, and nightclub styling.

### Implementation Defaults
Use the existing plain HTML, vanilla CSS, and browser JavaScript architecture. Reuse the current custom components, CSS tokens, GSAP motion layer, browser-local stores, and Node HTTP services. Prefer native controls and small reusable helpers over adding a frontend framework or component library.

### Design Principles
- Lead with the occasion and one obvious next action.
- Preserve editorial hierarchy before adding motion or decoration.
- Use product photography as useful browsing content, not atmospheric filler.
- Keep controls visible, keyboard-accessible, and comfortable on touch screens.
- State prototype limitations plainly; never imply payment, delivery, or stock certainty that does not exist.
